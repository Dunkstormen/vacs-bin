# vacs-bin

Automation repository for building and publishing the vacs-bin AUR package based on the upstream VACS project.

This repository automates packaging and publishing updates for the Arch Linux AUR package vacs-bin, using releases from the upstream VACS project.

Upstream project: https://github.com/vacs-project/vacs

## Features
- Automated AUR package updates
- Tracks upstream VACS releases
- Simplified release workflow
- Minimal maintenance setup
